- payer_name: string. Not nullable.
- member_id: string. Nullable.
- cpt_codes: list of strings. Not nullable, but may be an empty list.
- billed_amount: decimal number, 2 decimal places. Not nullable.
- patient_responsibility: decimal number, 2 decimal places. Not nullable.

Normalization rules:

- If a field is not present anywhere in the document, output it as JSON null. Never output an empty string for a missing field, and never omit the key — every one of the 8 keys must always appear in your output, even when its value is null.

- Currency amounts must be bare numbers, e.g. 1250.00, not "$1,250.00" and not a string.
- Dates must always be normalized to YYYY-MM-DD, regardless of how they appear in the source (e.g. "03/14/2026" or "March 3, 2026" both become the appropriate YYYY-MM-DD value).
- cpt_codes must preserve the order the codes appear in the document.

Output format:

Return only a single JSON object with exactly these 8 keys: patient_name, date_of_service, provider_npi, payer_name, member_id, cpt_codes, billed_amount, patient_responsibility.
